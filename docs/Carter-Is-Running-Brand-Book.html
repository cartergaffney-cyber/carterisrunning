Carter Is Running

Brand Statement

Every mile earns its place.

Carter Is Running is built for the long game — the early alarms, the empty streets, the miles that don't show up on a map until you've run them. It's not about being the fastest person on the course. It's about showing up, adapting to the road in front of you, and doing the work.

The identity retires the kettlebell and ocean wave of the brand it's descended from for iconography that's true to the sport: the road underfoot and the topographic contour lines of the terrain around it. No finish-line hero shots, no gear-snob elitism — just honest miles.

Using These Files

Two things to set up once, so everything above renders correctly on the live site.

01 · Load the font

Add this to your site's <head> once, globally:

<link href="https://fonts.googleapis.com/css2?family=Josefin+Slab:wght@300;400;600;700&display=swap" rel="stylesheet">

02 · Inline the lockups with text

The icon marks (no text) are safe to use as plain <img src="icon-…svg"> or favicons — they don't depend on any font.

The full lockups contain live text, so paste their SVG markup directly into your HTML instead of loading them with <img>. Browsers block external font loading inside <img>-referenced SVGs; inlining lets the logo pick up the Google Fonts link above.
